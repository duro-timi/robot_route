# The robot_route package 
- Author: Timi.
- This ROS package is a ROS1 based package that explores the visualization of a route for a robot to navigate.
- Rviz visualization makers is used to make the virtual route.
- A little user interface is also created to interract with the robot by controlling its linear and angular velocity.
- The robot is a cooper bot in the space station provided by the construct simulation environment.
